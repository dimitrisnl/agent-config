# Browser-assisted work

- Browser tools are welcome for verification, testing, debugging, and profiling.
- Use an already installed browser tool and its skill. Ask before installing anything new.
- Ask before browser use to avoid disrupting the user's work. Approval covers the agreed investigation, not each click; ask again if the scope changes.
- Follow local and repository instructions for access and setup.
- Collect useful evidence, but never commit it. Ask before deleting it; the user may need it later.
