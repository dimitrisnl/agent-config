## Local changes

- Rename the workflow to `clarify-before-build` and combine the wrapper and interview instructions into one explicit-only skill.
- Focus on decisions that affect implementation; stop when the work is clear enough to build rather than exhausting the entire design tree.
- Use small rounds of plain numbered questions with recommended answers instead of the fixed emoji-heavy format.
- Investigate available facts directly; delegation is optional and requires authorization, not mandatory for every lookup.
- Keep clarification read-only, with a conversational summary and user confirmation before implementation. Do not create planning files, glossaries, or ADRs automatically.

Review upstream changes manually against this revision and preserve intentional differences; no automatic sync is configured.
