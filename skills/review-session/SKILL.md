# Review a session

- Review the selected session for concrete mistakes or repeated friction.
- Tie each recommendation to an observed event and explain how it would address the problem. State when evidence is insufficient.
- Prefer the smallest durable fix: improve an existing instruction, remove a conflicting rule, or use an automated check where appropriate.
- Recommend at most three changes, with their targets and a way to evaluate them. No recommendations is a valid outcome.
- Propose changes only; do not apply them.
